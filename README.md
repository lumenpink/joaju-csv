# ssot-rs

Motor soberano em Rust para Fonte Unica de Dados (SSOT), projecoes e filtros tabulares

## 📋 Conformidade GOST

Este projeto adota a norma **[GOST](https://codeberg.org/lumenpink/gost)** (Gosplan Standard for Technical Software).
- **Versão GOST:** `1.1.0`
- **Linguagens declaradas:** `rust,shell`
- **Licença:** `Apache-2.0`

## 🚀 Como Iniciar

```bash
# Clonar o repositório
git clone <url-do-repositorio>
cd ssot-rs

# Verificar conformidade
cccp check
```
